# تحديث المحفظة والجوال وAZ ai

هذه حزمة كاملة لملفات الواجهة المعدلة، وليست patch ناقصًا.

## الملفات

| الملف | الرفع |
|---|---|
| `index.html` | استبدال الملف الموجود في جذر المستودع |
| `app.js` | استبدال الملف الموجود في جذر المستودع |
| `sw.js` | استبدال الملف الموجود في جذر المستودع |
| `manifest.json` وملفات الأيقونات | استبدال النسخ الموجودة |
| `watchlist_mode_migration.sql` | يُشغّل مرة واحدة في Supabase SQL Editor، ولا يُرفع كملف واجهة |

## الإصلاحات

أضيف اختيار `مراقبة وتنبيهات` أو `تسجيل شراء محاكى`، مع سعر الدخول والكمية. أصبحت بطاقة السهم تعرض الرمز، السعر، النوع، الكمية، والربح أو التراجع. أضيفت حماية لعرض قائمة المراقبة داخل Signal Grid على الجوال، مع شريط تنقل أفقي قابل للتمرير. أضيف موجز عودة في AZ ai عند العودة بعد انقطاع ثلاث ساعات، ويعرض الأسهم المحفوظة ودرجة الشركة وسبب الإشارة ومنطقة الدخول التعليمية عند توفرها. كما تُستبدل صيغة `n/n` غير الصالحة بشرطة عرضية.

## الترتيب

شغّل SQL أولًا في Supabase، ثم ارفع `index.html` و`app.js` و`sw.js` و`manifest.json` والأيقونات إلى جذر GitHub. بعد النشر امسح Cache الموقع أو افتحه في نافذة خاصة، ثم اختبر الإضافة على الجوال واللابتوب.

كل العمليات افتراضية وتعليمية فقط، ولا توجد أوامر تداول حقيقية.
